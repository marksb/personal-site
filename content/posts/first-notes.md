This site is up. It's built with [Hugo](https://gohugo.io/) and styled with
[Tailwind CSS](https://tailwindcss.com/), deployed straight from GitHub
Actions to GitHub Pages.

The goals were narrow: something minimal and quick to read, no tracking, no
comments, nothing fighting the text for attention. Everything here is
written in Markdown and checked into a plain git repo, which is about as
low-maintenance as a website gets.

More notes as I have them.
